# Trackware - Developer Work Intelligence

## Project Info

Track effort, monitor productivity, and detect risks early. A developer-focused work intelligence platform.

## Getting Started

### Prerequisites

- Node.js & npm installed

### Setup

```sh
# Step 1: Clone the repository
git clone <YOUR_GIT_URL>

# Step 2: Navigate to the project directory
cd trackware

# Step 3: Install dependencies
npm install

# Step 4: Start the development server
npm run dev
```

## Technologies Used

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
